# FUNPLAY Play Store checklist

- [ ] Set a unique Android application/package ID.
- [ ] Create a release keystore and configure signing.
- [ ] Configure production Supabase URL and anon/publishable key.
- [ ] Test signup, login, logout, feed, upload, likes, comments, rooms, realtime chat and quiz on physical Android devices.
- [ ] Add a privacy policy URL.
- [ ] Prepare app icon, feature graphic, screenshots and store description.
- [ ] Complete Google Play Data Safety declarations accurately.
- [ ] Complete content rating and target audience declarations accurately.
- [ ] Build a signed Android App Bundle (AAB).
- [ ] Upload the AAB to Google Play Console and resolve any pre-launch warnings.
